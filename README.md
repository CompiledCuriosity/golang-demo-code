# Go demo code

Runnable Go source for the videos on [Compiled Curiosity](https://www.youtube.com/@CompiledCuriosity).

Each video has its own folder holding the complete, compiling program and a README that explains it in more detail than the video has room for. Every folder README links back to its video.

The repo is one Go module, so a sample runs from the repo root:

```
go run ./<topic>
```

Go 1.21 or later.
